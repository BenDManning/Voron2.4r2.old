# Voron 2.4 R2 configuration archive

This repository is an old, automated backup of my Voron 2.4 R2 printer configuration. I stopped using the GitHub backup and keep the current configuration locally. **This is not the printer's current setup and is not actively maintained.**

The files include Klipper printer configurations and dated snapshots, Moonraker and Fluidd configuration, Euclid-related files, and the script that made automatic commits. They reflect the hardware, software, and tuning at the time each backup was made. Some snapshots may be incomplete or represent experiments in progress.

If you borrow anything from here, check the pin assignments, hardware limits, homing and probing setup, and macros against your own machine before using it. Do not copy the configuration wholesale onto another printer.

This archive also contains old machine-specific values and credentials from when it was used privately. They are historical and should not be reused.
